# 判例ノート

企業法務で使う重要判例と実務ポイントを、スマホで見られるノートアプリ（PWA）。

- 判例データは `data/` フォルダに分野ごとに書く（書き方は `cases.js` 先頭のコメント参照）。新しいファイルを作ったら `index.html` と `sw.js` にも追加する
- `url` に裁判所ウェブサイトの判例ページを入れると「全文を読む」ボタンになる
- ★・確認済み・自分メモは端末のブラウザ内に保存（画面下の「書き出す」でバックアップ）
- 判例を追加・修正したら `sw.js` の `VERSION` の数字を1つ上げる

判旨は原文ではなく要約。出典・日付・内容は原典で確認してから使うこと。

## 新着判例ウォッチ

- `.github/workflows/watch.yml` が毎朝9時（日本時間）に `automation/watch.mjs` を実行し、裁判所ウェブサイトの「最近の最高裁判例」「最近の下級裁裁判例」を巡回して `data/watch.js` を更新する
- 対象：最高裁（刑事は独禁法・金商法など企業関連のみ）、下級審の行政事件・労働関係・企業法務分野の民事事件
- GitHub の Actions タブから「新着判例ウォッチ」→「Run workflow」で手動実行もできる
